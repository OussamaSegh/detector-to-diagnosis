# Exercise 16.4: notes

**"Close it today, both defects are fixed."** The fixes are the correction, and they were done
before the CAPA was opened. The CAPA is about the cause: unit tests that do not reach the limits
of a type. Closing it now would record that the cause is removed when nobody has yet seen
whether the new rule and the new seeds stop the next such defect; the effectiveness check
says when that can be known (the campaigns of 0.4.0 and 0.5.0). If the organization needs the
action items off the list, the status is "implemented"; "closed" waits for the result.

**What the draft got wrong.** It was closed with a result ("no new problems so far") that would
also be true if nothing had changed; it named one of the two problem reports; it stopped at
"human error" and answered it with "be more careful" and training, which change nothing a check
can see; and its due date, "soon", can never be missed.
