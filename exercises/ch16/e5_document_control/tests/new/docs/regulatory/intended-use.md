# MiniDAQ intended use

Version 2 (MiniDAQ 0.3.0). Owner: software lead.

MiniDAQ acquires the list-mode data of a brain PET scanner for research and teaching. The
operator checks the integrity verdict of every run before the data is reconstructed.
