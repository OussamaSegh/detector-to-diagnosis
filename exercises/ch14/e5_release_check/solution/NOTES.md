# Exercise 14.5: notes

**What stays a human check.**

- That the evidence is the evidence of *this* commit: the tool sees that `logs/tests-tsan.log`
  exists, not that it was produced from the released commit. A real pipeline would attach the
  logs to the commit by its hash, or the record would be generated by the pipeline itself.
- That each known anomaly's evaluation is still right for this release: the tool sees that
  the report is listed, a person decides whether the decision "release with it" still holds.
- That the SOUP review covered every release of the supplier since the last one, and the
  issue tracker as well as the release notes.
- That the archive can be restored: once per release, someone builds from the archive alone.
- A "pass" with a story ("pass, one flaky test rerun") is not a pass. The tool refuses it,
  and the person who wants to release anyway has to write a problem report: the flaky test
  is an anomaly too.
