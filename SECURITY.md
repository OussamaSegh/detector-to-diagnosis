# Security policy

MiniDAQ is the teaching project of the book "The NeuroLF Engineer". It is not a medical device
and must not be used to acquire patient data. Its threat model and its vulnerability management
are described in [docs/regulatory/security/threat-model.md](docs/regulatory/security/threat-model.md).

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through GitHub's "Report a
vulnerability" button on the repository's Security tab (private vulnerability reporting), with
the version, the steps to reproduce and what you observed. You should get an answer within
14 days. We will agree on a disclosure date with you, fix the vulnerability in a new release,
and credit you in the advisory unless you prefer otherwise.

A real medical device manufacturer publishes the same information for its products, with its
own contact, response times and coordinated disclosure process.
