# Index terms of the book (book/filters/index-terms.lua).
#
# One entry per line: PHRASE | KEY. The filter adds \index{KEY} at the first place in each
# chapter where PHRASE appears in running text (not in headings, code blocks or captions).
# PHRASE is matched word by word, ignoring case and the punctuation around a word; the last
# word may take a plural "s" or "es". A PHRASE in backticks matches inline code exactly.
# KEY defaults to PHRASE; "!" separates a main entry from a subentry, as in makeindex.
# Spans written as [text]{.idx} in the chapters add entries too.
