# How to use this manual {.unnumbered}

This manual contains worked solutions to every exercise in *Detector to Diagnosis*
(version {{version}}) and model answers to every *Check yourself* question. The main book
stays exercise-first: try each exercise against its acceptance tests before you read the
solution here.

For coding exercises, the reference implementation is in the companion repository under
`exercises/chNN/<exercise>/solution/`, next to a `NOTES.md` that explains the design
choices. This manual walks through the reasoning, shows the key code, and lists the
mistakes the acceptance tests are designed to catch. Code is included from the
repository at build time, so it is the same code the repository's CI compiles and tests.

Model answers are deliberately compact. If your answer covers the same points in
different words, it is right. If it covers more, even better: write the extra point into
your learning log as a question for your team in your first weeks.
