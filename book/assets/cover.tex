% Color of block i of n: a blend between the two neighboring stops.
\newcommand{\blockcolor}[2]{%
  \pgfmathsetmacro{\t}{5*#1/#2}%
  \pgfmathtruncatemacro{\k}{floor(\t)}%
  \pgfmathtruncatemacro{\p}{100 - round(100*(\t-\k))}%
  \pgfmathtruncatemacro{\kn}{mod(\k+1,5)}%
  \colorlet{blk}{s\k!\p!s\kn}%
}

\newcommand{\nlfitem}{\par\hangindent=1em\hangafter=1\textbullet\enspace}
\ifx\nlfvolume\nlfsolutions
  \newcommand{\nlfblurb}{%
    \textbf{\fontsize{14}{18}\selectfont Solutions Manual}\par\medskip
    This manual holds a worked solution to every exercise in \emph{Detector to Diagnosis} and a
    model answer to every Check yourself question.\par\medskip
    Each solution walks through the reasoning, shows the key code and names the mistakes the
    acceptance tests are built to catch. The code is included from the companion repository,
    where every solution is compiled and passes its tests.\par\medskip
    Try each exercise against its acceptance tests first. Then read the solution here, and
    compare your design with the one in the repository.}
\else
  \newcommand{\nlfblurb}{%
    \textbf{\fontsize{14}{18}\selectfont Building regulated medical imaging software\newline in modern C++}
    \par\medskip
    A PET scanner turns tens of millions of detected photons per second into an image that a
    physician trusts. The software in between must keep up, lose nothing without saying so, and
    show an auditor why it is safe to ship.\par\medskip
    This book teaches you to build that software. Across its chapters you grow MiniDAQ, a
    simulated PET data acquisition system, from strong types and lock-free queues to a
    coincidence sorter, a crash-safe list-mode writer and a continuous integration pipeline
    whose results are verification records.\par\medskip
    You learn:\smallskip
    \nlfitem low-latency, real-time C++ on Linux, measured rather than guessed;
    \nlfitem the PET physics and readout a data acquisition engineer needs;
    \nlfitem IEC 62304, ISO 14971, ISO 13485 and medical device cybersecurity, applied to
    real code;
    \nlfitem testing, CI and debugging that produce evidence.\par\medskip
    Every chapter has graded exercises with acceptance tests and a milestone. Every listing is
    compiled and tested from the companion repository.}
\fi
