- `board_id`: Identifies the board; software checks MAGIC before it trusts any other register.
- `fw_version`: Firmware version; Chapter 24 checks it against the versions the software supports.
- `control`: Switches the bias and the trigger; a write of 1 to SOFT_RESET resets the board's logic.
- `status`: The board's present state; changes on its own.
- `error_flags`: Sticky errors: a bit stays set until software writes 1 to it.
- `fifo_level`: How full the board's output FIFO is (map 1.1, Chapter 24).
- `bias_setpoint`: The bias voltage the supply drives when BIAS_ENABLE is set.
- `bias_monitor`: The bias voltage the board measures at the SiPMs.
- `bias_current`: The current the bias supply delivers.
- `bias_ramp_rate`: The fastest the supply moves the bias, so that a step cannot damage the SiPMs.
- `temperature`: The temperature of the SiPM array, from the sensor on the board.
- `threshold`: The trigger threshold of the board's discriminator.
